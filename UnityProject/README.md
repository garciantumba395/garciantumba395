# Taxi Kin: Wewa, Taxi & 207 — projet Unity

## Mise en route
1. Unity Hub → **New project** (3D, Unity 2022.3 LTS ou plus récent ; URP recommandé pour mobile).
2. Copier le dossier `Assets/` de ce dépôt dans le nouveau projet (ou ajouter ce dossier via *Add project from disk* après avoir généré `ProjectSettings/`).
3. Menu **Taxi Kin → Créer la scène de test Main** : génère `Assets/Scenes/Main.unity`.
4. Ouvrir `Assets/Scenes/Main.unity` et appuyer sur Play.

Ne jamais versionner ni modifier `Library/`, `Temp/`, `Obj/`, `Builds/` (voir `.gitignore`).
